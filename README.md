# Qwik Service – Click-to-Call demo

Static demo site for the NiCE Cognigy Capstone Project (Use Case 1): a fictitious automotive service chain
whose voice agent "Quinn" (Cognigy.AI) books, checks, reschedules and cancels service appointments.

- `index.html` – landing page with Click-to-Call (Cognigy Click To Call SDK), caller-ID simulation, live transcript and xApp panel
- `advisor.html` – service advisor notifications (read-only, from the Advisor API)
- `vendor/` – `@cognigy/click-to-call-sdk` 0.2.0 (MIT, bundles JsSIP)

Hosted via GitHub Pages at https://call.qwik-service.online
